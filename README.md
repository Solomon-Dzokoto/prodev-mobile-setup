# Mobile Development Environment Setup

This document outlines the process of setting up the mobile development environment using Expo Go.

## Expo Go Setup

1.  **Visited the Expo Go Homepage:** Navigated to [https://expo.dev/go](https://expo.dev/go).
2.  **Selected SDK Version:** Chose the latest available SDK version.
3.  **Installed Expo Go:**
    *   **Android:** Installed from the Google Play Store.
    *   **iOS:** Installed from the Apple App Store.
4.  **Logged In:** Opened the Expo Go app and created a new account.

## Challenges Faced

*   No significant challenges were encountered during the setup process. The installation and login were straightforward.
