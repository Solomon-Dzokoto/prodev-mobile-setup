# First Mobile App

This document outlines the process of creating the first mobile app using Expo Router.

## Scaffolding Steps

1.  **Navigated to Project Directory:** `cd prodev-mobile-setup`
2.  **Initialized Expo Project:** `npx create-expo-app@latest .`
3.  **Modified Home Screen:** Changed the text in `app/(tabs)/index.tsx` to "** First App Created**".

## `npm run reset-project` Observations

Running `npm run reset-project` does the following:

*   Deletes the `node_modules` directory.
*   Deletes the `package-lock.json` file.
*   Clears the Metro bundler cache.

This is useful for starting with a clean slate and resolving potential dependency issues.
